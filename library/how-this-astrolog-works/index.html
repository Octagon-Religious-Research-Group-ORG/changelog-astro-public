How this AstroLog works

Where the changelog's source lives, how it reaches this public page, and how to add an entry.

TL;DR: Entries are Markdown files in a private repository. On every change, a workflow builds the site and publishes only the finished pages to a public repository, which GitHub Pages serves.
Read the full write-up

Two repositories

  • changelog-astro (private) holds the Markdown entries, the library, and the site’s source.
  • changelog-astro-public (public) holds only the built pages and the README.

A workflow in the private repository runs on every push. It builds the site with Astro, removes every source folder from the history, adds back only the built pages, and pushes the result to the public repository. Everything is private unless it is named on an allowlist, and the workflow stops if a new top-level folder appears that is on neither list. This pattern is shared with the Psychedelics in Recovery and Holy Earth Foundation AstroLogs.

Adding an entry

Create a file in changelog/ named YYYY-MM-DD-short-title.md:

---
title: "What changed, in plain words"
date: "2026-10-11"
priority: "P2-medium"
repo: "site"
---

<div class="tldr"><i class="ph ph-lightbulb"></i> <strong>TL;DR:</strong> One or two sentences.</div>

<details>
<summary><i class="ph ph-caret-right"></i> Read the full story</summary>

The full story, as long as it needs to be.

</details>
  • repo is the area: site, api, github, or previews.
  • priority shows on the page as Major (P1-high), Notable (P2-medium), or Small (P3-low).
  • Write for members, not developers. Name things by what people see.
  • Link to other pages here the short way, like /library/the-perforated-sheet. The build adds the site’s base path for you, so the link lands on this site rather than the organization’s root.
  • Nothing private: no member details, sign-in settings, or anything from the members-only repository.

Library write-ups go in library/ with a title and a one-sentence description.

The three lights and the ink

The site can be read in all three lights from Renan T’s design directions, which started the new builds and now live on as modes (their story is on Three directions, living together). Your choice is remembered and shared with the root page. Reading mode, the book button in the header, sets the calmest of them in one tap. The marbled ink behind the page is the same field as the dApp preview’s; it follows your pointer and can be paused from the header. It stays still for anyone who has reduced motion turned on.

Shared in Telegram, iMessage or Discord, it arrives with its own preview card.
