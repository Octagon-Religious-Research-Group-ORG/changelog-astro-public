How ORG's sites fit together

A map of ORG's websites and repositories: what runs where, who looks after what, and how the pieces connect.

TL;DR: orgspirituality.org is a TanStack Start site on Netlify, backed by a NestJS API, with member sign-in through Clerk. GitHub holds the code, the organization profile, the brand files, a root page, and this AstroLog.

The earlier site The first version, kept for reference ORG-Website
  • orgspirituality.org is built with TanStack Start and Tailwind CSS and deployed on Netlify, where its server functions run too. It has member sign-in, the offerings shop, search, and an in-browser editor for page content.
  • The API is a NestJS service. Its README documents a MongoDB Atlas connection, and its hosting runtime is configured for Heroku.
  • Sign-in runs through Clerk on both the site and the API, since August 2026. Before that it was Auth0.
  • Both repositories carry automated tests that cover their behavior in full.

Previews and proposals

  • Design directions: Renan T’s three proposed looks for the site (Night Sanctuary, Prism Light, Stone & Lapis), first offered to members for a vote. The proposal became the spark for the new builds and is now tabled; its story is kept on Three directions, living together, and its looks live on as the lights every ORG page offers.
  • dApp preview: Christopher’s personal preview of what the site could become. It is not ORG’s official site.
  • drasticstatic ORG lab: Christopher’s lab changelog and portfolio, covering the dApp preview and whatever else he builds for ORG. This AstroLog is the official record for the repositories in ORG’s own organization; the lab records the work that happens outside it.

The ledger

The ledger is the step-by-step record under the changelog: every public commit to ORG’s repositories, in plain words, sorted into kinds (new things, look and feel, words and pages, fixes, speed, sign-in, records, and work behind the scenes), credited the way this AstroLog credits people, and linked to the change on GitHub. It’s built from GitHub’s public history each time this site builds, which happens on every change and once a day. Merges, automatic publishing commits and bot chores are left out, and private repositories are never read.

Who looks after what

From ORG’s profile: Tripp A founded ORG and leads much of the site’s content and design. Renan T develops the website and drew up the design directions. JP M (mitch8020 on GitHub) built the original site and its API. Christopher looks after ORG’s GitHub and builds the previews, with Alfred.
